    Jammed Disposal Repair in Eden Prairie

    Jams usually trace back to one hard object, like a peach pit, a chicken bone or a twist tie wrapped around the impeller. We free the flywheel from below with the hex key and pull the object with pliers, never a hand, then run it with water to make sure nothing else is stuck. The reset button may need a press. Check the trap arm if it jams again.

    Noise and Odor Diagnosis in Eden Prairie

    A rattle that stops after a few seconds is usually a spoon or a pit bouncing in the chamber. A constant high whine means something else. A steady whine usually points to failing motor bearings, and the noise keeps building until the motor locks up. Odors usually trace to the splash guard. We pull it, clean the chamber walls and replace the guard if it is torn.

    Leaking Disposal Fix in Eden Prairie, MN
