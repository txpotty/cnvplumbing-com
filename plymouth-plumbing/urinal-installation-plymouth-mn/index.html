    Cracked or stained urinals are worth replacing. Cracked china leaks eventually and heavy scale rarely comes clean, so a new bowl on the old carrier is usually best. We check the carrier bolts first. Rusted bolts get replaced.

    Flush Valve Urinal Installation in Plymouth, MN

    Flush valve urinals are the commercial standard. A flushometer from Sloan or Zurn delivers a measured volume from a 3/4 inch supply with no tank, and it recovers instantly for the next user, which matters in a stadium or school restroom. We set the volume to the bowl. Wrong settings stain bowls.

    Residential Urinal Plumbing in Plymouth, MN

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Permit rules apply too. We check that first.

    Sensor Urinal Installation in Plymouth, MN

    Sensor valves stop missed flushes and double flushes. Battery or hardwired valves get a tuned sensing range and an optional sanitary flush for idle periods. Batteries last a few years. Hardwired units need an electrician first.

    ADA Urinal Installation in Plymouth

    Accessible urinals start at the carrier. The carrier gets set for a 17 inch rim, the floor space stays clear, and the flush control stays reachable. We measure the rim twice. Inspectors measure too.

    Sloan Flush Valve Installation in Plymouth, MN

    Sloan Royal valves are on most commercial urinals we see. Optima sensor valves fit the same spud. Battery models need no wiring.

    ADA-Compliant Urinal Installation in Plymouth

    At least one urinal in a public restroom with more than one usually has to be accessible. Flush controls must be reachable. We mark it all during rough-in.
